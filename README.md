# 融合多源特征的 KIT 胃肠间质瘤相关激酶苗头化合物机器学习定位

> 结合结构与序列特征，对 KIT 激酶相关苗头化合物进行精准定位，服务胃肠间质瘤与 AML 的靶向治疗探索。

## 一、方法

- **模型**：XGBoost 梯度提升树（Morgan 分子指纹）

- **输入**：Morgan 分子指纹（2048 bit）
- **训练规模**：2500 条样本，2 类
- **标签协议**：rel
- **验证**：5 折分层交叉验证 × 3 随机种子 = 15 次独立训练
